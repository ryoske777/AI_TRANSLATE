JSON을 붙여넣거나 파일을 올리면 파일명 / ID / type / 언어코드 구조의 엑셀로 변환합니다.

2. 미리보기

3. 다운로드

· 통합 파일: translations_날짜.xlsx 한 개 안에 itemInfo, Npcdata … 시트로 나뉩니다.
· 각각 저장: JSON의 키 이름 그대로 itemInfo.xlsx, Npcdata.xlsx … 여러 파일이 받아집니다. (브라우저가 연속 다운로드를 물어보면 허용)

변환 규칙

① 1행 1열 = .xlsx 파일명 (각 파일은 별도 시트)
② 1열 = ID (JSON의 숫자/영문 키). 2행부터 시작하며, 같은 ID의 여러 행은 첫 행에만 표시
③ ID 다음 단계의 키(identifiedDisplayName, descript …)는 type 열로. 단계가 더 깊으면 type2, type3… 이 자동 추가
④ ko-KR, en-US … 국가 코드는 항상 1행의 열로. JSON에서 몇 단계 아래에 있든 언어 단계를 찾아 가로로 펼칩니다
⑤ ID 바로 아래가 국가 코드면(Npcdata, mobdef 등) type 열 없이 출력
⑥ 언어 아래에 또 구조가 있으면("ko-KR": {"prev":…, "curr":…}) prev/curr가 type 열로 내려가고 언어는 열로 유지 → 한 행에 전 언어의 prev, 다음 행에 전 언어의 curr
